# Ledger AI

单人自用的本地 iPhone 账本，目标为 iOS 17 及以上。当前支持手动记账、流水编辑和撤销、月年统计、父子预算、按期间调额、预计报销及跨期到账。

## 换机开发

克隆仓库后，用 Xcode 16 或更高版本打开 Ledger.xcodeproj，选择 Ledger 和 iPhone 模拟器运行。安装到自己的手机时，在 Signing & Capabilities 选择开发团队，按需修改 Bundle Identifier。

账本逻辑在 Ledger/Core，SwiftUI 入口是 Ledger/LedgerApp.swift。使用完整 Xcode 的 Swift 6 工具链，在仓库根目录运行：

```sh
swift test
```

已有机器使用命令行工具运行了 12 项账本与查询测试，SwiftUI 通过 macOS SDK 类型检查。iOS 构建、界面操作及真机持久化仍待验收。

## 开发计划与验收约定

| 阶段 | 进度与验收 |
|---|---|
| 本地账本 | 已实现收支、转账、编辑、删除、操作历史、撤销和月年统计。 |
| 手建预算与报销 | 已覆盖 A08、A09、A14、A17 的核心逻辑，以及 A05 手动改账、A12 手建父子汇总。到账日冲减原分类，允许负已用额和高于额度的余额。年中启用按全年额度计算，余额旁提示记录起点。 |
| 换机首轮 | 在 iPhone 上复验调额、跨月及跨年报销、撤销与重启。用例数据和断言见 Tests/LedgerCoreTests/BudgetAcceptanceTests.swift。 |
| AI 录入与纠错 | 自配服务并承担费用，首次发送前授权。优先实现文字拆单、一次一张截图、模糊项补充、查询及分类纠正。首次安装可直接手记。 |
| 重试、判重与撤销 | 同一次发送重试只入账一次。独立输入且证据不足时直接新增；跳过项保留匹配对象，支持补记。整次撤销仅撤回该次写入，也可按指定流水撤销。 |
| AI 上下文与隐私 | 授权后发送近 72 小时全部流水的时间、金额、用途、已知商户和分类。明确补记更早日期时附相关候选。历史凭证留在本机。用户纠正形成可撤销、可跨会话使用的分类习惯。 |
| 数据与预算后续 | 补齐储备划拨及支用、外币待折算、访问保护、流水导出和可恢复的完整备份。完整个人模板等原始子项清单补齐后单独验收。 |
| 一周试用 | 核对随手记和集中补记的误跳过、纠正后分类和月度数字。多图批处理、历史导入、周报与预测留到后续。 |

本地查询目前覆盖验收短句，例如「这个月花了多少」「游戏预算还剩多少」「下月起交通预算改成每月 500」。
